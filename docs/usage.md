# 사용법

에어마우스를 실제로 쓰는 방법입니다. 빌드/개발 방법은 [개발 가이드](development.md)를 보세요.

## 처음 연결하기

1. **보드에 전원을 넣습니다.** USB-C 케이블을 꽂거나 배터리를 연결합니다. (파워 스위치를 달았다면 켜세요 — [배선 방법](hardware.md#파워-스위치는-enable-핀에-답니다))
2. **보드를 책상에 내려놓고 2~3초 기다립니다.** 이때 LED가 **주황색**이면 자이로 캘리브레이션 중이므로 **절대 움직이지 마세요** (아래 [캘리브레이션](#캘리브레이션) 참고).
3. LED가 **파랑 깜빡임**으로 바뀌면 BLE 광고 중입니다.
4. 맥에서 **시스템 설정 → Bluetooth**를 열고 목록에서 **`ESP32C3 AirMouse`** 를 연결합니다.
   - Windows는 **설정 → Bluetooth 및 장치 → 장치 추가 → Bluetooth**에서 동일하게 연결합니다.
5. LED가 **초록색**으로 바뀌면 연결 완료입니다. 이제 커서가 움직입니다.

두 번째부터는 페어링 정보가 보드에 저장되어 있어(NVS 본딩) 전원만 넣으면 자동으로 재연결됩니다.

## 잡는 방법과 조작

USB 커넥터가 **모니터를 향하도록** 손에 쥡니다. 이 방향이 기준이며, 다르게 쥐면 축이 어긋납니다.

| 동작 | 결과 |
|---|---|
| 손목을 좌우로 돌리기 (yaw) | 커서 좌우 이동 |
| 손목을 위아래로 기울이기 (pitch) | 커서 상하 이동 |
| 보드를 옆으로 눕히기 (roll) | 반응 없음 (의도된 동작) |
| **좌클릭 버튼** (GPIO3) | 좌클릭 |
| **우클릭 버튼** (GPIO4) | 우클릭 |
| **스크롤 ↑ 버튼** (GPIO5) | 위로 스크롤 |
| **스크롤 ↓ 버튼** (GPIO6) | 아래로 스크롤 |
| **BOOT 버튼** (온보드) | 자이로 재캘리브레이션 |

클릭 버튼은 누르고 있는 동안 계속 눌린 상태로 전달되므로 **드래그**도 됩니다. 빠르게 두 번 누르면 더블클릭입니다.

스크롤 버튼은 톡 누르면 한 칸만 움직이고, **계속 누르고 있으면 잠시 후부터 연속으로** 스크롤됩니다. 키보드 키를 누르고 있을 때와 같은 방식입니다.

> **클릭·스크롤 버튼 4개는 직접 배선해야 합니다.** 보드에 기본 탑재된 버튼이 아닙니다. 택트 스위치를 GPIO3~6과 GND에 연결하는 방법은 [하드웨어 문서의 버튼 배선](hardware.md#클릭과-스크롤-버튼-배선)에 있습니다. 배선 전에는 커서 이동과 BOOT 버튼만 동작합니다.

BOOT 버튼을 누르면 그 자리에서 자이로 영점을 다시 잡습니다. 커서가 흐를 때 전원을 다시 넣을 필요 없이 **보드를 내려놓고 BOOT를 한 번 누르면** 됩니다. LED가 주황으로 바뀌고 2~3초 뒤 원래대로 돌아옵니다.

마우스처럼 손을 들었다 내려놓는 "리프팅"은 없습니다. 자이로 기반이라 회전만 인식하고, 평행 이동은 무시합니다.

## LED 색깔의 의미

보드 가운데의 WS2812 RGB LED가 현재 상태를 나타냅니다. 밝기는 눈부심과 전류를 줄이려고 8%로 낮춰두었습니다.

| 색 | 상태 | 무엇을 해야 하나 |
|---|---|---|
| 🟠 **주황 (계속 켜짐)** | 자이로 캘리브레이션 중 | **보드를 움직이지 마세요.** 2~3초면 끝납니다 |
| 🔵 **파랑 (1초 주기 깜빡임)** | BLE 광고 중 — 호스트에 연결되지 않음 | 호스트에서 Bluetooth 연결을 하세요 |
| 🟢 **초록 (계속 켜짐)** | 연결됨 — 정상 동작 | 그냥 쓰면 됩니다 |

전원을 넣으면 보통 **주황 → 파랑 깜빡임 → 초록** 순서로 바뀝니다. 이미 페어링된 호스트가 근처에 있으면 파랑 구간이 매우 짧거나 건너뛸 수 있습니다.

### 충전 표시등 (빨간 LED)

위의 RGB LED와는 **별개인 작은 빨간 LED**가 배터리 충전 상태를 나타냅니다. 보드의 충전 IC(MCP73831)가 직접 켜고 끄는 하드웨어 표시등이라 펌웨어와 무관하게 항상 동작합니다.

| 빨간 LED | 의미 |
|---|---|
| 켜짐 | **충전 중** |
| 꺼짐 | **충전 완료**, 또는 USB 미연결, 또는 배터리 미장착 |

꺼져 있는 상태가 "충전 완료"인지 "배터리가 없는지"는 LED만으로 구분되지 않습니다. 이 LED는 GPIO에 연결되어 있지 않아 펌웨어가 상태를 읽을 수 없고, 따라서 RGB LED로 충전 상태를 표시하거나 호스트에 배터리 잔량을 보고하는 것도 불가능합니다. 자세한 배경과 개조 방법은 [하드웨어 문서의 충전 회로](hardware.md#충전-회로와-배터리-상태)를 보세요.

## 캘리브레이션

부팅할 때마다 자이로의 영점(바이어스)을 다시 측정합니다. LED가 주황인 약 2.6초 동안입니다.

**이 구간에 보드가 움직이면 안 됩니다.** 움직인 상태의 각속도를 "정지 상태"로 학습하면, 이후 가만히 있어도 커서가 한쪽으로 계속 흐릅니다.

다만 안전장치가 있어서, 정지로 볼 수 없는 샘플(어느 축이든 20dps 초과)은 평균에서 자동으로 제외됩니다. 크게 흔들렸다면 그만큼 시간이 더 걸릴 뿐 잘못된 값이 학습되지는 않습니다. 계속 움직이면 캘리브레이션이 실패하고 부팅이 중단됩니다.

커서가 흐른다면 **보드를 책상에 내려놓은 채로 전원을 다시 넣는 것**이 가장 확실한 해결책입니다.

## 문제 해결

### 목록에 `ESP32C3 AirMouse`가 안 보여요

LED를 먼저 확인하세요. 파랑 깜빡임이 아니면 광고 중이 아닙니다.

- **LED가 꺼져 있음** → 전원이 안 들어온 상태입니다. 케이블/배터리를 확인하세요.
- **LED가 주황에서 안 바뀜** → 캘리브레이션이 끝나지 않았습니다. 보드를 내려놓으세요.
- **파랑 깜빡임인데도 안 보임** → 맥에서 이전 페어링 기록을 지우고(Bluetooth 목록에서 해당 기기 **연결 해제**) 다시 검색해 보세요.

### 연결은 됐는데 커서가 안 움직여요

LED가 초록인지 확인하세요. 초록인데도 안 움직인다면 대부분 호스트 쪽 문제입니다. 보드 전원을 다시 넣어 재연결해 보세요.

### 커서가 저절로 한쪽으로 흘러요

캘리브레이션 중 보드가 움직였을 가능성이 높습니다. 보드를 책상에 내려놓고 전원을 다시 넣으세요.

재부팅해도 계속 흐른다면 데드존을 올려야 합니다 — [튜닝 가이드](tuning.md#정지-시-커서가-흐를-때)를 보세요.

### 커서가 너무 느려요 / 너무 빨라요

감도(`GAIN`) 조정이 필요합니다. [튜닝 가이드](tuning.md#감도-조정)에 상수 하나만 바꾸는 방법이 있습니다.

### 커서가 반대 방향으로 움직여요

보드를 쥔 방향이 기준(USB 커넥터가 모니터 쪽)과 다를 수 있습니다. 방향을 바꿔 쥐어도 계속 반대라면 [튜닝 가이드](tuning.md#방향-뒤집기)에서 부호를 뒤집으면 됩니다.

### 배터리로 쓰려면 뭘 더 해야 하나요

**배터리를 `BAT+`/`BAT−` 패드에 연결하는 것만으로 끝입니다.** 보드에 USB/배터리 자동 절체 회로가 들어 있어서, USB를 꽂으면 USB로 구동되며 배터리를 충전하고 USB를 빼면 자동으로 배터리 구동으로 넘어갑니다. 다이오드나 스위치를 추가할 필요가 없습니다.

충전 전류가 100mA로 고정되어 있어 900mAh급 배터리는 완충에 9~10시간 걸립니다. 자세한 내용은 [하드웨어 문서](hardware.md#배터리는-연결만-하면-됩니다)를 보세요.

### 배터리가 얼마나 남았는지 보고 싶어요

보드에 배터리 전압 측정 회로가 없어서(MCP73831은 충전만 지원) 잔량을 알 수 없습니다. 호스트에 표시되는 배터리 잔량은 100% 고정값입니다. 하드웨어 제약입니다.
